# DocuLight Viewer v1.0.3 Release Notes

## Critical Reliability Fix

- **Settings freeze resolved** -- Replaced full indexing-job history materialization and redaction with a bounded SQLite aggregate status query.
- **Non-overlapping Settings polling** -- Indexing and embedding status share a single-flight adaptive poller with 500 ms active updates.
- **Bounded worker status writes** -- Worker progress bursts are coalesced while cancellation and terminal states remain durable.
- **Lower startup recovery memory** -- Recovered indexing jobs defer document content loading until worker execution.

## Release Safety

- Windows, macOS, and Linux releases run the complete regression and worker benchmark gate before package smoke and artifact publication.
- The release workflow restores the Electron test binary after an `ignore-scripts` dependency install so post-build Node regression tests can load Electron consistently on every platform.
- Release tags must match both the package version and the exact build commit.

# DocuLight Viewer v1.0.3 릴리즈 노트

## 중요 안정성 수정

- **설정 화면 멈춤 해결** -- 전체 인덱싱 작업 이력의 객체화·비식별화 대신 크기가 제한된 SQLite 집계 상태 조회를 사용합니다.
- **설정 상태 조회 중첩 방지** -- 인덱싱·임베딩 상태를 단일 실행 적응형 폴러로 통합하고 작업 중 500ms 갱신을 유지합니다.
- **워커 상태 쓰기 제한** -- 진행 상태 폭주를 병합하면서 취소와 종료 상태는 내구성 있게 보존합니다.
- **시작 복구 메모리 절감** -- 복구 작업의 문서 내용은 큐에 보관하지 않고 워커 실행 시점에 읽습니다.

## 릴리스 안전성

- Windows, macOS, Linux 릴리스는 패키지 스모크와 아티팩트 게시 전에 전체 회귀 및 워커 벤치마크 게이트를 실행합니다.
- `ignore-scripts` 의존성 설치 후 Electron 테스트 바이너리를 복원해 모든 플랫폼의 빌드 후 Node 회귀 검사가 Electron을 동일하게 로드합니다.
- 릴리스 태그는 패키지 버전과 실제 빌드 커밋에 모두 정확히 일치해야 합니다.
