# DocuLight Viewer v1.0.4 Release Notes

## Cross-platform Path Reliability

- **Knowledge-store aliases stay contained** -- Opened Markdown registration now compares canonical roots before deciding whether a document is inside the configured store.
- **No duplicate `.opened` copy** -- Files reached through Windows 8.3 short paths, directory junctions, symbolic links, or macOS `/var` aliases retain their configured-store path and use legacy adoption without copying.
- **Nested escapes are rejected** -- An inside-looking symlink or junction that resolves outside the configured store returns a redacted containment diagnostic without copying or indexing the file.
- **Regression coverage** -- A real symlink/junction fixture verifies that an aliased store path queues the original document and never creates the opened-document namespace.

## Settings Freeze Hotfix

- The bounded indexing-status aggregate, single-flight adaptive Settings poller, coalesced worker progress, and deferred startup content loading from v1.0.3 remain included.
- Windows, macOS, and Linux publication remains gated by the complete release regression suite, worker benchmark, and packaged-app smoke test.
- Failed `v1.0.2` and `v1.0.3` tags remain immutable; `v1.0.4` identifies the corrected build commit.

# DocuLight Viewer v1.0.4 릴리즈 노트

## 교차 플랫폼 경로 안정성

- **지식 저장소 별칭을 내부 경로로 유지** -- 열린 Markdown 등록 시 정규화된 실경로 루트를 비교해 문서가 설정된 저장소 내부인지 판정합니다.
- **`.opened` 중복 복사 방지** -- Windows 8.3 짧은 경로, 디렉터리 junction, 심볼릭 링크, macOS `/var` 별칭을 통한 파일도 설정된 저장소 경로를 유지하고 복사 없이 legacy adoption을 사용합니다.
- **중첩 경로 이탈 차단** -- 내부 경로처럼 보이지만 설정된 저장소 밖으로 연결되는 symlink/junction은 파일을 복사하거나 인덱싱하지 않고 비식별화된 containment 진단을 반환합니다.
- **회귀 검사 추가** -- 실제 symlink/junction fixture로 별칭 저장소의 원본 문서가 큐에 등록되고 opened-document namespace가 생성되지 않음을 검증합니다.

## 설정 화면 멈춤 핫픽스

- v1.0.3의 크기가 제한된 인덱싱 상태 집계, 단일 실행 적응형 설정 폴러, 워커 진행 상태 병합, 시작 복구 내용 지연 로딩을 그대로 포함합니다.
- Windows, macOS, Linux 게시는 전체 릴리스 회귀 검사, 워커 벤치마크, 패키지 앱 스모크를 모두 통과해야 합니다.
- 실패한 `v1.0.2`와 `v1.0.3` 태그는 이동하지 않고 보존하며, `v1.0.4`가 수정된 빌드 커밋을 식별합니다.
