# DocuLight Viewer v1.0.0 Release Notes

## Highlights
- **Resilient search indexing** -- Rebuilding now clears and recreates the index with live progress, queued-file, failure, and recovery status. On the next launch, an interrupted rebuild automatically starts a fresh replacement rebuild.
- **Semantic and hybrid search** -- Configure an embedding model independently of BM25 indexing, recover gracefully when the embedding service is unavailable, and use hybrid retrieval with link-graph filtering.
- **Richer document viewing** -- Added document navigation breadcrumbs, pasted absolute Markdown-path opening, code-block copy controls, and improved image and Mermaid viewing with inline zoom and dedicated viewer windows.

## MCP and Packaging
- **Packaged CLI MCP server** -- The installed application now includes a stdio CLI MCP entry point alongside the existing HTTP transport.
- **Document save and smart search tools** -- MCP clients can save a Markdown document without opening a viewer window and use read-only hybrid `smart_search` retrieval.
- **Release package validation** -- Package smoke checks verify the native search modules and packaged MCP resources before release artifacts are published.

## Configuration and Reliability
- **Search index management** -- The settings UI now keeps index counters and current work visible in real time, and prevents actions that need a configured document storage path when one is absent.
- **Embedding connection validation** -- Embedding settings validate the connection in the background and enable connection only when the configured endpoint is reachable.

# DocuLight Viewer v1.0.0 릴리즈 노트

## 주요 변경
- **복원력 있는 검색 인덱싱** -- 다시 만들기는 기존 인덱스를 제거한 뒤 처음부터 생성하며, 진행률·대기 파일·실패·복구 상태를 실시간으로 표시합니다. 작업 중단 후 다시 실행하면 미완료 리빌드를 처음부터 다시 만들도록 자동으로 예약합니다.
- **시맨틱 및 하이브리드 검색** -- 임베딩 모델을 BM25 인덱스와 독립적으로 설정하고, 임베딩 서비스 연결이 끊겨도 안전하게 동작하며, 링크 그래프 필터를 포함한 하이브리드 검색을 지원합니다.
- **향상된 문서 보기** -- 문서 이동 경로, 절대 경로 Markdown 붙여넣기 열기, 코드 블록 복사 제어, 인라인 확대/축소와 전용 창을 포함한 이미지·Mermaid 보기를 추가했습니다.

## MCP 및 패키징
- **설치형 CLI MCP 서버** -- 기존 HTTP 전송과 함께 설치형 앱에서 stdio 기반 CLI MCP 진입점을 제공합니다.
- **문서 저장 및 스마트 검색 도구** -- MCP 클라이언트가 뷰어 창을 열지 않고 Markdown 문서를 저장하고, 읽기 전용 하이브리드 `smart_search` 검색을 사용할 수 있습니다.
- **릴리스 패키지 검증** -- 릴리스 아티팩트를 게시하기 전에 네이티브 검색 모듈과 패키징된 MCP 리소스를 스모크 테스트로 검증합니다.

## 설정 및 안정성
- **검색 인덱스 관리** -- 설정 화면에서 인덱스 수치와 현재 작업을 실시간으로 표시하며, 문서 저장 경로가 없는 경우 해당 경로가 필요한 동작을 막습니다.
- **임베딩 연결 검증** -- 임베딩 설정은 백그라운드에서 연결을 검증하고, 설정한 엔드포인트에 연결할 수 있을 때만 연결 버튼을 활성화합니다.
