# DocuLight Viewer v0.10.15 Release Notes

## Bug Fixes
- **OAuth discovery endpoint handling** -- The MCP HTTP server now returns JSON 404 responses for `.well-known/oauth-*` and `.well-known/openid-configuration` probing requests, preventing `SyntaxError` in Claude Code's HTTP transport client.

## Improvements
- **CORS Authorization header support** -- Added `Authorization` to the allowed CORS headers, enabling authenticated MCP client connections.
- **MCP protocol version update** -- Updated `PROTOCOL_VERSION` from `2025-03-26` to `2025-11-25` to align with the latest MCP Streamable HTTP specification.

# DocuLight Viewer v0.10.15 릴리즈 노트

## 버그 수정
- **OAuth discovery 엔드포인트 처리** -- MCP HTTP 서버가 `.well-known/oauth-*` 및 `.well-known/openid-configuration` 프로빙 요청에 JSON 404 응답을 반환하도록 수정하여 Claude Code HTTP 트랜스포트 클라이언트의 `SyntaxError`를 방지.

## 개선 사항
- **CORS Authorization 헤더 지원** -- 허용 CORS 헤더에 `Authorization`을 추가하여 인증된 MCP 클라이언트 연결 지원.
- **MCP 프로토콜 버전 업데이트** -- `PROTOCOL_VERSION`을 `2025-03-26`에서 `2025-11-25`로 업데이트하여 최신 MCP Streamable HTTP 사양에 맞춤.
