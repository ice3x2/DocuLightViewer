## §1 Overview

### 1.1 Goal

Implement `REL-DOC-007` for DocuLight 0.11.0-w2 by moving search index maintenance work that can block Electron out of the main process, while preserving Settings-only controls, read-only MCP search behavior, committed index safety, and measurable responsiveness under large indexing workloads.

### 1.2 In Scope

- Worker or child-process isolation for full keyword rebuild, SQLite FTS writes, tokenizer enrichment, SQLite compact/VACUUM, embedding batch work, and HNSW build/compact.
- Worker-owned SQLite write connection and committed-generation protection for keyword rebuild.
- Durable job phase/progress/heartbeat/cancel state that Settings can read.
- Bounded Korean/basic tokenizer enrichment and no query-time HNSW rebuild.
- Settings UX guards, WAL/SHM-aware backup/checkpoint messaging, packaged worker native smoke, and opt-in temp-index large-corpus benchmark.

### 1.3 Out Of Scope

- Adding MCP tools for rebuild, clear, retry, cancel, status, model changes, import, or reconciliation.
- Replacing the existing `search_documents` compatibility contract.
- Promoting `REL-DOC-007` to stable before implementation, benchmark, package smoke, and review evidence exist.
- Running the large-corpus benchmark against the user's real app index or userData directory.

### 1.4 Assumptions

- `REL-DOC-007` is the only planned new-work candidate for active target `0.11.0-w2`.
- Existing Wave 1, Wave 1.5, and Wave 2 verified requirements remain source-of-truth dependencies.
- New tests may introduce new files under `test/` and `scripts/`; implementation must preserve unrelated dirty worktree changes.
- Native worker smoke may accept `native_unavailable` degradation for optional HNSW, but better-sqlite3 worker load must be explicitly verified or fail with a user-facing diagnostic.
- Planned new files are intentionally listed without line ranges: `src/main/search-index-worker-controller.js`, `src/main/search-index-worker.js`, `test/test-search-index-worker-contract.js`, `test/test-search-index-worker-benchmark-contract.js`, `scripts/bench-search-index-worker.js`, and `docs/analysis/kiwi-review-fix-loop-2026-07-05.doculight.index-worker/report.md`.
