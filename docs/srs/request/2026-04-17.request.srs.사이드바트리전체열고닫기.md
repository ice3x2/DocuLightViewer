# 요구사항 정리 — 사이드바 트리 전체 열기/닫기

**작성일**: 2026-04-17
**요청자**: ice3x2
**원본 요청**: 파일 리스트 창 상단에 검색 아이콘과 태그 아이콘이 있는 위치에 90도 회전된 `<>` 아이콘과 `><` 아이콘 버튼을 넣으려고 합니다. 각각의 아이콘은 모두 닫기와 모두 열기 버튼입니다. 즉 디렉토리 내의 문서들을 모두 닫거나 모두 열 수 있습니다.

## 의도 요약

사이드바(파일 리스트) 헤더에 **전체 접기(collapse all) / 전체 펼치기(expand all)** 버튼 2개를 추가하여 사용자가 트리 구조의 모든 디렉토리를 한 번에 토글할 수 있게 한다.

## 목표

1. 트리 구조의 모든 디렉토리 노드를 단일 클릭으로 전체 접을 수 있어야 한다.
2. 트리 구조의 모든 디렉토리 노드를 단일 클릭으로 전체 펼칠 수 있어야 한다.
3. 사용자 원안에 따라 두 버튼을 사이드바 헤더(현재 🏷️ / 🔍 버튼 위치)에 배치한다.

## 제약사항

- 기존 사이드바 헤더 레이아웃과 스타일을 유지해야 한다.
- 기존 버튼(이름 토글, 검색)과 동일한 스타일/크기로 통일한다.
- 4개 로케일(ko/en/ja/es)의 aria-label/title 문자열을 함께 추가한다.
- 보안 모델(CSP, contextBridge) 변경 없음 — 순수 렌더러 측 DOM 조작으로 구현.

## 우선순위

P2 (일반 — 이번 주 내)

## 사용자 유형

DocuLight 주 사용자(기술 문서 편집/열람자).

## 열린 질문 (2인 분석에서 확정)

- 아이콘 구현 방식(Unicode vs SVG vs 텍스트)
- 버튼 배치 순서(Navigation 레이블과의 상대 위치)
- 검색 모드 활성 상태에서의 동작
- `__external_links__` 가상 디렉토리 처리
- 가시성 상태 영구 저장 여부
- 키보드 단축키 필요 여부
