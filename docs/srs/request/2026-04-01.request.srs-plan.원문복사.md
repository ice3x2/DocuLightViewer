# 요구사항 정리 문서: 원문 복사

## 사용자 원문
문서가 열려있는 상황에서 마우스 오른쪽 버튼을 눌러 나오는 컨텍스트 메뉴에 "원문 복사" 기능을 추가해야합니다. 이곳에서 지원하는 다국어 기능을 적용해야 합니다. 원문 복사시 markdown 원문이 클립보드로 복사됩니다.

## 요약
뷰어의 컨텍스트 메뉴에 마크다운 원문 복사 기능 추가 (4개 언어 i18n 지원)

## 목표
- 렌더링된 문서의 마크다운 소스를 클립보드로 복사할 수 있도록 한다

## 변경 유형
feature

## 제약사항
- 기존 컨텍스트 메뉴 구조/패턴 준수
- 4개 언어(ko, en, ja, es) i18n 키 동시 추가
- originalContent (MCP/붙여넣기) 또는 파일 읽기 (filePath 기반) 두 경로 모두 지원
