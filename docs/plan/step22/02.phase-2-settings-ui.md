> 📌 **재활용**: 기존 `populateForm()`, `collectFormValues()`, `DEFAULTS` 패턴

- [ ] `DEFAULTS` 객체에 추가:



- [ ] `updateAutoSavePathState()` 수정 (line 388-394):
  - **변경 전**: 체크박스 OFF → 경로 입력 `disabled`, 그룹 `opacity: 0.5`
  - **변경 후**: 체크박스 OFF → 경로 입력 **활성 유지**, 그룹 `opacity: 1`

  ```javascript
  function updateAutoSavePathState() {
    // 체크박스 상태와 무관하게 경로 입력은 항상 활성
    // (자동 저장 OFF에서도 수동 저장에 경로 사용)
  }
  ```

  > **핵심 변경**: 이 함수의 본문을 **비우거나** opacity/disabled 로직을 제거한다. 함수 자체는 유지 (호출부 호환).

- [ ] (?) 도움말 버튼 이벤트:
  ```javascript
  var subdirHelpBtn = document.getElementById('mcpSaveSubDir-help-btn');
  var subdirHelpModal = document.getElementById('subdir-help-modal');
  if (subdirHelpBtn && subdirHelpModal) {
    var helpBody = document.getElementById('subdir-help-body');
    subdirHelpBtn.addEventListener('click', function() {
      if (helpBody) helpBody.textContent = t('settings.mcpSaveSubDirHelpContent');
      subdirHelpModal.classList.remove('hidden');

    // 닫기: 버튼 클릭 또는 오버레이 클릭 또는 Escape
    subdirHelpModal.querySelector('.modal-close-btn').addEventListener('click', function() {
      subdirHelpModal.classList.add('hidden');
    });
    subdirHelpModal.addEventListener('click', function(ev) {
      if (ev.target === subdirHelpModal) subdirHelpModal.classList.add('hidden');
    });
  }
  ```

## 테스트 시나리오

**TC-2-01: 레이블 확인**
- Given: 설정 창 열기
- When: MCP 저장 섹션 확인
- Then: "MCP로 불러온 문서 저장" 레이블 표시

**TC-2-02: 체크박스 OFF에서 경로 입력 가능**
- Given: 자동 저장 체크박스 OFF
- When: 경로 입력란 확인
- Then: 입력란과 찾아보기 버튼이 활성 (disabled 아님)

**TC-2-03: 포매터 (?) 도움말 팝업**
- Given: 설정 창의 포매터 입력란
- When: (?) 버튼 클릭
- Then: 토큰 설명 팝업 표시. Escape/외부클릭으로 닫힘

**TC-2-04: 포매터 값 저장/로드**
- Given: 포매터에 `{yyyy-mm-dd}` 입력 후 저장
- When: 설정 창 다시 열기
- Then: 포매터 입력란에 `{yyyy-mm-dd}` 유지
