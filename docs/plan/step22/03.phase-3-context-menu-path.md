    document.body.appendChild(menu);
    var rect = menu.getBoundingClientRect();
    var x = e.clientX, y = e.clientY;
    if (x + rect.width > window.innerWidth) x = window.innerWidth - rect.width - 4;
    if (y + rect.height > window.innerHeight) y = window.innerHeight - rect.height - 4;
    menu.style.left = x + 'px';
    menu.style.top = y + 'px';
    function closeMenu(ev) {

        document.removeEventListener('keydown', escH);
      }
    }
    setTimeout(function() {

      document.addEventListener('keydown', escH);
    }, 0);

## 테스트 시나리오

### 정상 케이스

**TC-3-01: 사이드바 파일 경로 복사**
- Given: 사이드바에 파일 목록 표시
- When: 파일 항목 우클릭 → "경로 복사"
- Then: 절대 경로 클립보드 복사, "경로가 복사되었습니다" 토스트

**TC-3-02: 사이드바 디렉토리 탐색기 열기**
- Given: 사이드바에 디렉토리 항목
- When: 디렉토리 우클릭 → "파일 탐색기에서 열기"
- Then: OS 탐색기가 해당 디렉토리 **내부**를 표시

**TC-3-03: 뷰어 Ctrl+Shift+C — MCP 저장 파일**
- Given: MCP 문서가 수동 저장된 상태
- When: Ctrl+Shift+C
- Then: 저장 경로가 클립보드에 복사, 토스트 표시

### 예외 케이스

**TC-3-04: 미저장 MCP 문서에서 Ctrl+Shift+C**
- Given: MCP 문서 열렸으나 저장 안 됨
- When: Ctrl+Shift+C
- Then: "먼저 문서를 저장해주세요" 토스트 (분홍색)

**TC-3-05: Save As 후 경로 복사 우선순위**
- Given: MCP auto-save 완료 (savedFilePath 존재) + Save As 완료 (saveAsFilePath 존재)
- When: Ctrl+Shift+C
- Then: saveAsFilePath가 복사됨 (사용자가 직접 선택한 경로 우선)

### 경계값

**TC-3-06: `node.exists === false` 항목**
- Given: 사이드바에 존재하지 않는 파일 항목 (opacity 0.5)
- When: 우클릭
- Then: 컨텍스트 메뉴 표시, 경로 복사 가능, 탐색기 열기 시 OS 기본 동작
