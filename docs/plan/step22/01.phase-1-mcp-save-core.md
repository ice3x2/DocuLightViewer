- [ ] `handleMcpSave()` 함수 추가
  ```javascript
  async function handleMcpSave() {
    if (!isMcpDocument) return;
    var params = buildSaveParams();  // ← 기존 함수 재활용
    if (!params) return;
    params.title = document.title || '';
    params.project = currentProject || '';
    var result = await window.doclight.mcpManualSave(params);
    if (result.success) {
      savedFilePath = result.filePath;
      showViewerToast(t('viewer.savedToast') + ': ' + result.filePath);
    } else {
      showViewerToast(t(result.errorKey) + (result.errorDetail ? ': ' + result.errorDetail : ''), 'error');
    }
  }
  ```

- [ ] 키보드 단축키 추가 (기존 `keydown` 리스너 내부, `Ctrl+Shift+S` 블록 **앞에** 배치)
  ```javascript
  // Ctrl+S: MCP manual save — Shift/Alt 없는 경우만
  if (mod && !e.shiftKey && !e.altKey && e.key === 's') {
    e.preventDefault();
    handleMcpSave();
    return;
  }
  ```

## 테스트 시나리오

### 정상 케이스

**TC-1-01: 수동 저장 성공**
- Given: `mcpAutoSave=false`, `mcpAutoSavePath="D:\docs"`, MCP 문서 열림
- When: Ctrl+S
- Then: `D:\docs\HHMMSS_파일명.md` 생성, 성공 토스트

**TC-1-02: 포매터 적용 자동 저장**
- Given: `mcpAutoSave=true`, `mcpSaveSubDir="{yyyy-mm-dd}"`, MCP `open_markdown` 호출
- When: 자동 저장 실행
- Then: `basePath/2026-03-17/HHMMSS_파일명.md` 생성

### 예외 케이스

**TC-1-03: 경로 미설정 수동 저장**
- Given: `mcpAutoSavePath=""`, MCP 문서
- When: Ctrl+S
- Then: 분홍색 에러 토스트 "저장 경로가 설정되지 않았습니다"

**TC-1-04: 비-MCP 문서에서 Ctrl+S**

- Then: 아무 동작 없음
