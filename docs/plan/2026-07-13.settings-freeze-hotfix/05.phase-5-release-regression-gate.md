## Acceptance

- tag/workflow_dispatch release는 Wave 1/2 또는 worker contract/benchmark 실패 시 artifact를 배포하지 않는다.
- 각 플랫폼의 기존 packaged native smoke가 계속 실행된다.
- workflow dispatch는 검증 성공 전 tag를 만들지 않으며 다른 commit의 기존 tag를 재사용하지 않는다.
- tag push는 실제 trigger tag가 `v${packageVersion}`과 일치하고 그 tag가 `$GITHUB_SHA`를 가리킬 때만 release한다.
- hotfix는 기존 release identity를 재사용하지 않고 `v1.0.2` release identity와 release note를 사용한다.
- release workflow contract가 세 job의 순서와 release job의 tag provenance 검사를 검증한다.
