## Concurrency Invariants

- indexing status in-flight <= 1.
- embedding status in-flight <= 1.
- active cadence 500 ms, idle cadence 3000 ms.
- success/rejection과 무관하게 poll coordinator `finally`에서 다음 timer가 하나만 예약된다.
- unload/stop 이후 timer와 후속 IPC는 없다.
