## 개요

Step 26은 DocuLight에 두 가지 UX 개선을 추가한다:

1. **사이드바 이름 토글**: 파일명 ↔ frontmatter `name` 필드 전환 버튼
2. **하단 이전/다음 박스**: Docusaurus 스타일의 문서 연속 탐색 UI
