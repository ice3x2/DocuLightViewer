# Phase 2: 사이드바 이름 토글 버튼

## Phase 2: 사이드바 이름 토글 (FR-26-001)

### 목표
사이드바 헤더에 `#btn-sidebar-name-toggle` 버튼을 추가하고, 클릭 시 파일 노드 표시명이 파일명 ↔ frontmatter `name` 필드로 전환된다.

---

  - **대상 파일**: `src/renderer/viewer.js`
  - **삽입 위치**: `renderSidebarTree` 함수 정의 바로 앞 (L1572 이전)
  - ⚠️ 이 함수는 파일 노드 전용. 디렉토리/가상 노드는 호출 전에 caller가 판별해야 함 (Phase 2-4 참고)
  ```javascript
  /**
   * 이름 토글 상태에 따라 파일 노드 표시명 반환
   * isDirectory/isVirtual 노드는 caller(renderTreeNode, updateDocNavBox)에서 제외 후 호출
   * @param {Object} node - 파일 노드 (isDirectory: false)
   * @returns {string} 표시명
   */
  function getDisplayName(node) {
    const state = window.DocuLight && window.DocuLight.state;
    if (state && state.showFrontmatterName &&
        node.frontmatterName && node.frontmatterName.trim() !== '') {
      return node.frontmatterName;
    }
    return node.title || '';
  }
  ```

## 언어+버전 주의사항
- 렌더러: 브라우저 JS (ES2020, Vanilla), `class` 문법 없이 함수형
- `aria-pressed` 값은 반드시 문자열 `"true"` / `"false"` (`setAttribute` 사용, 불리언 아님)
- `document.getElementById` — 항상 null 체크 (초기화 타이밍)
- 다크 테마: CSS 변수 `--link-color`, `--highlight-bg`가 다크 테마에서 다른 값이므로 하드코딩 금지

---

## LLM 코딩 주의사항
- **Simplicity**: `getDisplayName`은 본문 6줄 이내 (JSDoc 주석 제외). 조건 분기를 더 추가하지 않는다. isDirectory 판별은 caller(Phase 2-4)가 담당하므로 함수 내부에 추가하지 않는다.
- **Surgical**: `renderTreeNode()` 수정은 L1634-1636 단 3줄만. 함수 시그니처, 노드 클릭 핸들러, 클래스 관리 로직 일체 건드리지 않는다.
- **이벤트 이름 통일**: Phase 2-7에서 사용하는 커스텀 이벤트 이름은 반드시 `doculight:searchmode`로 통일. `sidebar-search.js` dispatch와 `viewer.js` subscribe 양쪽 모두 동일한 이름 사용.

## 테스트 시나리오

### 정상 케이스
- Given: 사이드바에 파일 목록 표시, 일부 파일에 `name: "표시이름"` frontmatter 있음
  When: `#btn-sidebar-name-toggle` 클릭
  Then: frontmatter name 있는 파일은 "표시이름"으로 표시, 없는 파일은 기존 파일명 유지. 버튼 `aria-pressed="true"`, `.active` 클래스 추가

### 예외 케이스
- Given: 사이드바 트리 없는 상태 (앱 시작 직후 파일 미열림)
  When: `#btn-sidebar-name-toggle` 확인
  Then: 버튼 `disabled` 상태 (클릭 불가)

### 경계값 테스트
- Given: `name: ""` (빈 문자열), `name: " "` (공백), `name` 없는 파일들이 혼합된 사이드바
  When: 토글 활성화
  Then: 빈/공백 name 파일은 파일명 표시, 유효한 name 있는 파일만 name 값으로 표시
- Given: 사이드바 검색 모드 활성화 상태
  When: `#btn-sidebar-name-toggle` 클릭 시도
  Then: 토글 상태 변화 없음 (클릭 무시)
