## Phase 6: BM25 검색 인덱싱 확장

### 목표

`search-engine.js`의 BM25 인덱싱 대상에 `gitBranch`와 `gitLastCommit` 필드를 추가하여 브랜치명/커밋 메시지로 저장된 문서를 검색할 수 있도록 한다.

### 선행 조건

- Phase 2 완료 (프론트매터에 git 필드가 포함된 문서가 저장됨)

### 기존 코드 재사용 힌트

- `src/main/search-engine.js:230` — `ovFldNames` 배열: `['project', 'docName', 'docType']`

### 구현 체크리스트

- [ ] Phase 6-1: `search-engine.js`의 `ovFldNames`에 `gitBranch`, `gitLastCommit` 추가 `FR-24-006`

### 언어+버전 주의사항

- CJS 모듈
- `wink-bm25-text-search`의 `ovFldNames`에 추가된 필드는 문서에 없으면 자동 무시

### LLM 코딩 주의사항

- **Simplicity**: 배열에 2개 문자열 추가가 전부. 다른 코드 수정 불필요
- **Surgical**: `ovFldNames` 배열만 수정. 검색 로직, 인덱싱 로직, `docMeta` 구조 수정 금지

### 상세 구현 명세

#### Phase 6-1: ovFldNames 확장

**현재** (line ~230):
```javascript
const ovFldNames = ['project', 'docName', 'docType'];
```

**변경:**
```javascript
const ovFldNames = ['project', 'docName', 'docType', 'gitBranch', 'gitLastCommit'];
```

> `gitRemote`와 `projectPath`는 URL/경로이므로 **제외** — 검색 노이즈 방지. 사용자가 브랜치명(`feature/auth`)이나 커밋 메시지(`fix: login bug`)로 검색하는 것이 주요 유스케이스.

### 테스트 시나리오

#### 정상 케이스
- **Given**: `gitBranch: "feature/auth"` 프론트매터 포함 문서가 저장됨
- **When**: `search_documents({ query: "feature/auth" })` MCP 호출
- **Then**: 해당 문서가 검색 결과에 포함

#### 예외 케이스
- **Given**: git 필드 없는 기존 저장 문서
- **When**: `search_documents({ query: "main" })` 호출
- **Then**: git 필드 없는 문서는 본문 매칭으로만 검색. 인덱싱 에러 없음

#### 경계값 테스트
- **Given**: `gitLastCommit: "fix: 한글 커밋 메시지 with English mixed"` 포함 문서
- **When**: `search_documents({ query: "한글 커밋" })` 호출
- **Then**: 한국어 토크나이저로 분석되어 검색 결과에 포함
