## Phase 5: 메타박스 렌더링 및 i18n 확장

### 목표

`viewer.js`의 `renderMetabox`에 git 필드 i18n 레이블을 추가하고, 4개 로케일 파일에 번역 키를 추가한다.

### 선행 조건

- Phase 2 완료 (프론트매터에 git 필드가 포함된 콘텐츠가 렌더러에 도달)

### 기존 코드 재사용 힌트

- `src/renderer/viewer.js:358-364` — `fieldLabels` 객체 (현재 5개 키)
- `src/locales/ko.json:134-139` — `viewer.meta*` 키 패턴
- `src/locales/ko.json:19-25,62-70` — `settings.*` 키 패턴

### 구현 체크리스트

- [ ] Phase 5-1: `viewer.js` `renderMetabox` fieldLabels에 4개 키 추가 `FR-24-005`
- [ ] Phase 5-2: `ko.json`에 viewer.meta* + settings.* 키 추가 `FR-24-005`
- [ ] Phase 5-3: `en.json`에 동일 키 추가 `FR-24-005`
- [ ] Phase 5-4: `ja.json`에 동일 키 추가 `FR-24-005`
- [ ] Phase 5-5: `es.json`에 동일 키 추가 `FR-24-005`

### 언어+버전 주의사항

- JSON 파일 편집 시 trailing comma 주의 (JSON은 trailing comma 허용하지 않음)
- `t()` 함수는 키가 없으면 키 자체를 반환 — partial 배포 시 graceful fallback

### LLM 코딩 주의사항

- **Simplicity**: `fieldLabels`에 키만 추가. `renderMetabox` 로직 수정 없음 (이미 범용적)
- **Surgical**: 로케일 파일에서 기존 키 수정 금지. 새 키만 추가

### 테스트 시나리오

#### 정상 케이스
- **Given**: git 정보가 포함된 프론트매터가 있는 마크다운 렌더링
- **When**: 메타박스 확인
- **Then**: "프로젝트 경로", "Git Remote", "브랜치", "마지막 커밋" 행이 올바른 레이블로 표시

#### 예외 케이스
- **Given**: 로케일이 `en`으로 설정됨
- **When**: git 정보 포함 문서 렌더링
- **Then**: "Project Path", "Branch", "Last Commit" 등 영문 레이블 표시

#### 경계값 테스트
- **Given**: git 필드 중 일부만 있는 프론트매터 (gitBranch 없음)
- **When**: 메타박스 렌더링
- **Then**: 존재하는 필드만 표시. 빈 행 없음
