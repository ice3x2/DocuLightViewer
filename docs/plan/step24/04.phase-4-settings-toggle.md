## Phase 4: 설정 토글 및 UI (`mcpGitInfo`)

### 목표

`mcpGitInfo` boolean 설정을 electron-store에 추가하고, Settings UI에 체크박스를 배치한다.

### 선행 조건

- Phase 3 완료 (MCP 핸들러가 `store.get('mcpGitInfo')` 참조)

### LLM 코딩 주의사항

- **Simplicity**: 기존 `mcpAutoSave` 체크박스와 100% 동일한 패턴. 새로운 UI 패턴 도입 금지
- **Surgical**: MCP 섹션 내에서만 수정. 다른 섹션(테마, 폰트 등) 절대 수정 금지

### 상세 구현 명세

#### Phase 4-1: electron-store 스키마

**`index.js`** — `mcpSaveSubDir` 뒤에 추가:
```javascript
mcpGitInfo: { type: 'boolean', default: true },
```

#### Phase 4-2: settings.html

**`mcpAutoSave` 블록(`mcpSaveSubDir-group`)과 버튼 그룹 사이에** 삽입:
```html
<div class="form-group">
  <div class="checkbox-group">
    <label class="checkbox-label">
      <input type="checkbox" id="mcpGitInfo-checkbox">
      <span data-i18n="settings.mcpGitInfo">Git 정보 자동 수집</span>
    </label>
    <small class="hint" data-i18n="settings.mcpGitInfoHint">
      MCP 문서에 프로젝트 경로가 제공되면 git 정보를 프론트매터에 자동 추가
    </small>
  </div>
</div>
```

#### Phase 4-3: settings.js

**DEFAULTS** (line ~62):
```javascript
mcpGitInfo: true,
```

**populateForm** (mcpSaveSubDir 처리 뒤에):
```javascript
const mcpGitInfoEl = document.getElementById('mcpGitInfo-checkbox');
if (mcpGitInfoEl) mcpGitInfoEl.checked = settings.mcpGitInfo ?? DEFAULTS.mcpGitInfo;
```

**collectFormValues** (mcpSaveSubDir 처리 뒤에):
```javascript
const mcpGitInfoEl = document.getElementById('mcpGitInfo-checkbox');
values.mcpGitInfo = mcpGitInfoEl ? mcpGitInfoEl.checked : DEFAULTS.mcpGitInfo;
```

### 테스트 시나리오

#### 정상 케이스
- **Given**: Settings 화면 열림
- **When**: "Git 정보 자동 수집" 체크박스 해제 후 저장
- **Then**: `store.get('mcpGitInfo')` === `false`

#### 예외 케이스
- **Given**: config.json에 `mcpGitInfo` 키가 없음 (업그레이드 시나리오)
- **When**: 앱 실행
- **Then**: `store.get('mcpGitInfo')` === `true` (기본값)

#### 경계값 테스트
- **Given**: `mcpGitInfo: false` 설정 상태
- **When**: `open_markdown({ content: "...", projectPath: "/work/proj" })` MCP 호출
- **Then**: 프론트매터에 `projectPath`만 포함, git 명령 실행 안 됨
