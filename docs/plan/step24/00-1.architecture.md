## 데이터 흐름

### 정상 흐름

```
projectPath("C:/Work/proj")
  → path.isAbsolute() === true
  → store.get('mcpGitInfo') === true
  → collectGitInfo("C:/Work/proj")
    → Promise.all([
        execGit(['remote','get-url','origin'], cwd) → "https://github.com/user/repo.git"
        execGit(['branch','--show-current'], cwd)   → "main"
        execGit(['log','-1','--format=%s'], cwd)    → "feat: something"
        execGit(['rev-parse','--show-toplevel'],cwd) → "/c/Work/proj"
      ])
    → sanitizeRemoteUrl("https://user:pass@github.com/...") → "https://github.com/..."
    → truncateCommit(subject, 200)
    → { project:"proj", projectPath:"C:/Work/proj",
        gitRemote:"https://github.com/...", gitBranch:"main",
        gitLastCommit:"feat: something" }
  → injectFrontmatter(content, { ...existingMeta, ...gitInfo })
  → YAML frontmatter prepended to content
```

### 실패 흐름

```
projectPath("./relative")
  → path.isAbsolute() === false
  → SKIP (git 수집 안 함, projectPath도 프론트매터에 미포함)

projectPath("C:/nonexistent")
  → path.isAbsolute() === true
  → collectGitInfo("C:/nonexistent")
    → 4개 execFile 모두 ENOENT (cwd 없음) → [null, null, null, null]
    → { project:"nonexistent", projectPath:"C:/nonexistent" }
  → frontmatter에 project + projectPath만 기록

projectPath("C:/no-git-dir")
  → collectGitInfo("C:/no-git-dir")
    → 4개 git 명령 모두 "fatal: not a git repository" → [null, null, null, null]
    → { project:"no-git-dir", projectPath:"C:/no-git-dir" }

git 미설치:
  → execFile('git', ...) → ENOENT ("git" not found) → [null, null, null, null]
  → 동일하게 graceful 처리

부분 실패 (detached HEAD):
  → remote: "https://..." (성공)
  → branch: "" (빈 문자열 → null)
  → log: "abc123" (성공)
  → rev-parse: "/c/Work/proj" (성공)
  → { project:"proj", projectPath:"...", gitRemote:"...", gitLastCommit:"abc123" }
  → gitBranch 생략

타임아웃 (느린 remote):
  → remote: TIMEOUT 5초 → null
  → branch: "main" (성공)
  → log: "feat: x" (성공)
  → rev-parse: "/c/Work/proj" (성공)
  → { project:"proj", projectPath:"...", gitBranch:"main", gitLastCommit:"feat: x" }
  → gitRemote 생략
```
