### 주요 기술 결정 (ADR 요약)

- **ADR-1** 순수 DOM 조작 — IPC/contextBridge 확장 없음. 이유: 트리 렌더링이 이미 직접 DOM 빌드 기반.
- **ADR-2** 인라인 SVG 아이콘 채택 (이모지 대신) — 플랫폼별 렌더링 차이 회피 + 기존 FAB 버튼 시각 언어 일관성.
- **ADR-3** 세션 내 상태만 유지 — `electron-store` 저장 없음. 파일 전환 시 `_startSidebarTreeLoad`로 재렌더되어 자연 무효화.
- **ADR-4** 가상 디렉토리(`__external_links__`) 포함 — 사용자에게 보이는 모든 접힘 가능 노드 일관 처리.
- **ADR-5** `updateSidebarToggleButtons()`는 **기존 Phase 2 IPC 리스너 내부에서 호출**하여 step28과 경합 방지. 별도 리스너 추가 금지.

### 시스템 구조 개요

```
viewer.html (Phase 1)
    │  #btn-sidebar-collapse-all + #btn-sidebar-expand-all (SVG)
    ▼
viewer.css (Phase 1)
    │  기존 #btn-sidebar-name-toggle/.search CSS 셀렉터 확장
    ▼
locales/*.json × 4 (Phase 1)
    │  sidebar.collapseAll, sidebar.expandAll, sidebar.*Title 키 추가
    ▼
viewer.js (Phase 2)
    │  collapseAll/expandAll/updateSidebarToggleButtons 3함수
    │  기존 IPC/searchmode 리스너 내부에서 update 호출
    ▼
sidebar-search.js 재사용 (변경 없음, doculight:searchmode CustomEvent 이벤트 재활용)
    ▼
Phase 3: 테스트 (AC-001~013 수동·자동 혼합)
```
