### IMPL-29-004: `collapseAllSidebarDirs()` 구현 `FR-001 AC-001 AC-007`

- [ ] `src/renderer/viewer.js`의 IIFE 내부, 기존 `showSidebarSpinner` 함수 근처에 신규 함수 추가:
  ```js
  function collapseAllSidebarDirs() {
    const container = document.getElementById('sidebar-tree');
    if (!container) return;
    const childrenEls = container.querySelectorAll('.tree-children');
    for (const el of childrenEls) {
      el.style.display = 'none';
      // 앞 형제 .tree-item의 .tree-toggle 문자 갱신
      const item = el.previousElementSibling;
      if (item && item.classList.contains('tree-item')) {
        const tog = item.querySelector('.tree-toggle');
        if (tog && tog.textContent) tog.textContent = '▶';
      }
    }
  }
  ```

### IMPL-29-006: `updateSidebarToggleButtons()` 구현 `FR-003 FR-004 FR-005 AC-004 AC-005 AC-006 AC-012`

- [ ] 통합 상태 관리 함수 신규 추가. **단일 진입점** 역할:
  ```js
  // 검색 모드 상태는 sidebar-search.js의 doculight:searchmode 이벤트로 추적.
  // 선언 위치: step28의 `_currentTreeLoadId` 바로 아래 (IIFE 내부, 전역 누출 금지)
  let _sidebarSearchModeActive = false;

  function updateSidebarToggleButtons() {
    const collapseBtn = document.getElementById('btn-sidebar-collapse-all');
    const expandBtn  = document.getElementById('btn-sidebar-expand-all');
    if (!collapseBtn || !expandBtn) return;

    const treeState = window.DocuLight && window.DocuLight.state
      ? window.DocuLight.state.sidebarTree : null;
    const treeEmpty = !treeState
      || !treeState.children
      || treeState.children.length === 0;

    const loading = _currentTreeLoadId !== 0;
    const disabled = _sidebarSearchModeActive || loading || treeEmpty;

    collapseBtn.disabled = disabled;
    expandBtn.disabled   = disabled;
  }
  ```
- [ ] 우선순위 규칙(AC-012): `disabled = 검색모드 || 로딩 || 트리부재` (OR 논리)

## 언어+버전 주의사항

- **Vanilla JS + IIFE** — 모든 함수는 기존 IIFE 내부에 선언. 전역 누출 금지.
- **`querySelectorAll` 반환** — Live NodeList가 아니므로 반복 중 DOM 변경에 안전.
- **`previousElementSibling`** — Node 20 + Electron 33에서 완전 지원. IE 호환 불필요.
- **옵셔널 체이닝(`?.`)** — Node 20 지원. 필요 시 사용.
- **addEventListener cleanup** — IIFE 종료 시점이 없으므로 `cleanups` 배열이 실질 무효하지만, 기존 관행 준수 목적으로 등록.

---

## LLM 코딩 주의사항

1. **Simplicity**: 3함수 외에 추가 유틸 함수 작성 금지. `performance.now()` 등 측정 코드는 Phase 3(테스트)에서만 추가.
2. **Surgical**: 기존 `renderTreeNode` / `renderSidebarTree` / `onSidebarTree*` 핸들러의 **본체 로직 변경 금지**. 오직 끝줄에 `updateSidebarToggleButtons()` 호출 한 줄만 주입.
3. **State reuse**: `_currentTreeLoadId`는 step28에서 이미 선언됨. **재선언 금지**. 같은 변수 참조.
4. **searchmode 이벤트 재사용**: `sidebar-search.js`에서 이미 디스패치되는 이벤트를 **수신**만 추가. 이벤트 형식(`detail.active`) 변경 금지.
5. **AC-012 우선순위**: disabled 판정은 반드시 OR 논리(검색 ∨ 로딩 ∨ 트리부재). AND로 잘못 구현 시 3개 중 1개만 걸려도 통과하는 버그 발생.
6. **초기 렌더 시점 호출**: Phase 1에서 HTML에 `disabled` 기본값이 있으므로 JS 로딩 지연 시에도 안전하지만, JS 초기화 끝에서 `updateSidebarToggleButtons()` 1회 호출하여 상태 명시적 확정.

## 테스트 시나리오

### 정상 케이스

- **Given**: `docs/plan/step28.../` 같은 중첩 3단계 폴더의 `.md` 파일이 열려있다.
  **When**: 사용자가 "모두 펼치기" 버튼을 클릭한다.
  **Then**: 모든 `.tree-children`의 `display='block'`, 모든 디렉토리 `.tree-toggle`이 `▼`로 표시된다.

- **Given**: 일부만 펼쳐진 혼합 상태.
  **When**: "모두 접기" 클릭.
  **Then**: 1회 클릭으로 모든 디렉토리가 접힌다.

### 예외 케이스

- **Given**: 검색 모드(`Ctrl+Shift+F`) 활성화된 상태.
  **When**: 두 버튼의 DOM 상태를 확인한다.
  **Then**: 두 버튼 `disabled === true`이며 클릭해도 함수가 호출되지 않는다.

- **Given**: 대용량 폴더 스트리밍 로딩 중(`_currentTreeLoadId !== 0`, 스피너 표시).
  **When**: 버튼 상태 확인.
  **Then**: 두 버튼 `disabled === true`. `sidebar-tree-done` 수신 후 검색 모드 아니고 트리 존재하면 `disabled === false`.

- **Given**: 어떤 파일도 열려있지 않아 `window.DocuLight.state.sidebarTree === null`.
  **When**: 버튼 상태 확인.
  **Then**: 두 버튼 `disabled === true`.

### 경계값

- **Given**: 검색 모드 활성 + 로딩 중 동시 상태.
  **When**: `sidebar-tree-done` 수신(로딩 완료).
  **Then**: 검색 모드가 여전히 활성이므로 두 버튼 `disabled === true` 유지 (AC-012 OR 논리).

- **Given**: 트리에 가상 디렉토리 `__external_links__` 포함.
  **When**: "모두 접기" 클릭.
  **Then**: 가상 디렉토리의 `.tree-children`도 `display='none'`이 된다.

- **Given**: 트리가 500 파일 + 20 디렉토리.
  **When**: "모두 접기" 클릭.
  **Then**: `performance.now()` 측정 50ms 이내 완료 (NFR-001).
