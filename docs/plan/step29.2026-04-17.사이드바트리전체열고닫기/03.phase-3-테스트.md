## 언어+버전 주의사항

- **Playwright Electron 모드** — `workers: 1` 직렬 유지. 기존 DocuLight 실행 중이면 포트/IPC 충돌.
- **Node 20 `performance.now()`** — 렌더러 내 `window.performance.now()`도 동일 정밀도 제공.
- **테스트 fixtures** — 실제 Downloads 등 절대 경로 의존 금지. `os.tmpdir()` + `fs.mkdtempSync()` 사용.

---

## LLM 코딩 주의사항

1. **Simplicity**: 기존 E2E 스위트 확장이 번거로우면 Node 레벨 스모크 테스트 + 수동 체크리스트로 충분. Playwright 자동화는 필수 아님.
2. **Surgical**: 기존 `sidebar-async.e2e.js`를 건드리지 말고 새 파일로 분리. import/fixture만 재사용.
3. **회귀 우선**: Phase 3의 핵심은 "신규 기능 검증"보다 "기존 기능 회귀 없음"이다. 기존 4개 단위 테스트가 전부 PASS인 것이 완료 조건.
