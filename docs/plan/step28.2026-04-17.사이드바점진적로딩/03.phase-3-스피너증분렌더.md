# Phase 3: 로딩 스피너 + 증분 렌더링 — 4건

## Phase 3: 사용자 가시적 UI 레이어 구현

### 목표

사용자 원안 "회색 원 세 개가 번갈아 커졌다 작아졌다 하는 로딩 아이콘"을 CSS로 구현하고, 배치 IPC 이벤트를 받아 DOM을 증분 추가한다. 소규모 폴더는 기존과 동일하게 한 번에 렌더링되고, 대규모 폴더만 스트리밍 경로로 동작한다.

### 선행 조건

- Phase 2 완료 (IPC 4종 이벤트 수신 가능)

| `src/renderer/sidebar-search.js` | 기존 `showLoading()` 스타일 패턴 참고 (단, 별도 스피너로 구현) |

---

### 코드 중복 주의

- 기존 `renderSidebarTree(tree)` 전체 렌더링 경로는 **유지**. `done` 이벤트에서 최종 트리를 받으면 기존 경로로 완전 대체 렌더(= append된 부분 트리를 전체 완성본으로 교체).
- 스피너 DOM은 `#sidebar-tree` 내부가 아닌 **형제 요소**로 배치하여 `container.innerHTML = ''` 시 스피너가 함께 지워지지 않게 함.
- `sidebar-search.js`의 `showLoading()`은 "검색 로딩"용. 이 Phase에서는 별도 스피너로 분리 (공유 시 상태 충돌).

- [ ] 스피너 show/hide 함수:
  ```javascript
  function showSidebarSpinner() {
    const el = document.getElementById('sidebar-loading-spinner');
    if (!el) return;
    _spinnerRefCount++;
    el.style.display = 'flex';
    el.setAttribute('aria-hidden', 'false');
  }
  function hideSidebarSpinner() {
    const el = document.getElementById('sidebar-loading-spinner');
    if (!el) return;
    _spinnerRefCount = Math.max(0, _spinnerRefCount - 1);
    if (_spinnerRefCount === 0) {
      el.style.display = 'none';
      el.setAttribute('aria-hidden', 'true');
    }
  }
  function forceHideSidebarSpinner() {
    const el = document.getElementById('sidebar-loading-spinner');
    if (!el) return;
    _spinnerRefCount = 0;
    el.style.display = 'none';
    el.setAttribute('aria-hidden', 'true');
  }
  ```
- [ ] 필요한 경우 exports 객체(라인 2382 근처)에 테스트 노출: `showSidebarSpinner`, `hideSidebarSpinner`

#### IMPL-28-010: 배치 수신 → 증분 DOM 추가

**대상**: `src/renderer/viewer.js`

- [ ] 초기화 함수 근처에 4종 리스너 등록 (`onSidebarTree` 근처):
  ```javascript
  window.doclight.onSidebarTreeStart(({ loadId, rootPath, fromCache }) => {
    _currentTreeLoadId = loadId;
    if (!fromCache) showSidebarSpinner();
    // 초기 빈 상태 준비
    const container = document.getElementById('sidebar-tree');
    if (container) container.innerHTML = '';
  });

  window.doclight.onSidebarTreeBatch(({ loadId, nodes }) => {
    if (loadId !== _currentTreeLoadId) return;  // 구 로드 잔여 드롭
    appendPartialNodesToSidebar(nodes);
  });

  window.doclight.onSidebarTreeDone(({ loadId, tree }) => {
    if (loadId !== _currentTreeLoadId) return;
    // 완성 트리로 깨끗하게 재렌더 (정렬/링크마킹/외부노드 반영)
    renderSidebarTree(tree);
    hideSidebarSpinner();
    _currentTreeLoadId = 0;
  });

  window.doclight.onSidebarTreeError(({ loadId, reason }) => {
    if (loadId !== _currentTreeLoadId) return;
    hideSidebarSpinner();
    if (reason === 'aborted') {
      // 전환 중이므로 DOM 유지 (다음 start가 곧 옴)
    } else {
      // 실제 에러 — 빈 사이드바 유지
      const container = document.getElementById('sidebar-tree');
      if (container) container.innerHTML = '';
    }
    _currentTreeLoadId = 0;
  });
  ```
- [ ] 기존 `onSidebarTree` 리스너(라인 643~647)는 **유지**하되 중복 렌더 방지 가드:
  ```javascript
  window.doclight.onSidebarTree(({ tree }) => {
    if (_currentTreeLoadId !== 0) return;  // 스트리밍 경로가 처리 중
    renderSidebarTree(tree);
  });
  ```

### 언어+버전 주의사항

- **DOMPurify 영향 없음**: 사이드바 트리는 DOMPurify를 거치지 않음. `data-*` 속성 유지 가능.
- **CSS 변수 fallback**: `var(--text-muted, #888)` 패턴으로 라이트/다크 양쪽 커버.
- **`aria-hidden`**: 스피너 숨김 상태에서 스크린 리더가 "로딩 중" 반복 낭독 방지.
- **DocumentFragment**: 여러 `appendChild`를 한 번에 반영해 리페인트 횟수 감소.

---

### LLM 코딩 주의사항

1. **기존 `renderSidebarTree` 재구현 금지**: 기존 함수는 done 이벤트에서 완성 트리를 받아 전체 재렌더 시 사용. 중간 배치는 `appendPartialNodesToSidebar`로 처리.
2. **중복 렌더 방지**: `onSidebarTree` 기존 이벤트와 `onSidebarTreeDone` 이벤트가 둘 다 오면, `_currentTreeLoadId` 가드로 한 번만 렌더.
3. **스피너 DOM을 `#sidebar-tree` 외부에 두기**: 내부에 두면 `innerHTML = ''` 에서 함께 지워짐.
4. **aria-hidden 토글 누락 금지**: 접근성 테스트 실패 원인.
5. **Simplicity**: 가상 스크롤링, 무한 스크롤, 진행률 % 표시 금지. MVP 범위 초과.
6. **Surgical**: `viewer.js`의 다른 이벤트 리스너/초기화 로직 수정 금지. 추가만.
7. **`buildSidebarNodeElement` 추출은 조심**: 기존 `renderTreeNode`의 재귀 로직에서 순수 "단일 노드 빌드" 부분만 빼낸다. 잘못 빼내면 기존 렌더링이 깨짐. 먼저 기존 함수 구조를 읽고 분리 지점을 확인할 것.

### 테스트 시나리오

#### 정상 케이스
- **Given**: 대형 폴더 열기 (500 파일)
  **When**: start/batch×10/done 순차 수신
  **Then**: 스피너 즉시 표시 → 배치별 DOM 추가 → done에서 완성 트리로 한 번 재렌더 → 스피너 숨김

- **Given**: 소형 폴더 열기 (10 파일)
  **When**: start/batch×1/done 수신
  **Then**: 스피너 깜빡이지만 기능상 동일. 최종 트리 정상 표시

#### 예외 케이스
- **Given**: start 수신 후 error(`aborted`) 수신
  **When**: 폴더 전환
  **Then**: 스피너 숨김 + 기존 부분 DOM은 유지(즉시 새 start가 곧 옴 → 새 start에서 innerHTML=''로 리셋)

- **Given**: start → error(`error`) 수신
  **When**: 실제 실패
  **Then**: 스피너 숨김 + 사이드바 빈 상태

- **Given**: `_currentTreeLoadId=7` 상태에서 loadId=5의 batch 도착
  **When**: 경합 발생
  **Then**: 배치 무시(드롭)

#### 경계값
- **Given**: 스피너가 이미 보이는 상태에서 show 중복 호출
  **When**: show 2회 → hide 1회
  **Then**: refCount=1, 스피너 유지. hide 추가 1회 시 숨김.

- **Given**: 스피너 DOM 요소가 없는 환경(HTML 변경 누락)
  **When**: show 호출
  **Then**: 조용히 무시 (예외 throw 금지)
