- [ ] `const BATCH_SIZE = options.batchSize || 50;` 지역 변수로 사용
- [ ] 함수 진입 시 `if (options.signal?.aborted) throw new Error('Aborted')` 가드

#### IMPL-28-002: 50파일 청크 × `Promise.all` 병렬 + 배치 yield

**대상**: `src/main/link-parser.js` — `buildDirectoryTree` 내 `.md` 파일 처리 루프

- [ ] `.md` 파일 목록을 `BATCH_SIZE`(50) 단위로 슬라이스:
  ```javascript
  const mdFiles = entries.filter(e => e.isFile() && e.name.toLowerCase().endsWith('.md'));
  const limited = mdFiles.slice(0, available);

  const children = [];
  for (let i = 0; i < limited.length; i += BATCH_SIZE) {
    if (options.signal?.aborted) throw new Error('Aborted');
    const chunk = limited.slice(i, i + BATCH_SIZE);
    const batchNodes = await Promise.all(chunk.map(async (file) => {
      const filePath = path.join(rootDir, file.name);
      let fmName = null;
      try {
        const content = await fs.promises.readFile(filePath, 'utf-8');
        fmName = parseFrontmatterName(content);
      } catch { /* 무시 */ }
      return { path: filePath, title: file.name, frontmatterName: fmName, isDirectory: false };
    }));
    children.push(...batchNodes);
    if (typeof options.onBatch === 'function') {
      try { options.onBatch(batchNodes); }
      catch (cbErr) { console.warn('[doculight] onBatch callback error:', cbErr.message); }
    }
  }
  ```
- [ ] 하위 디렉토리 재귀는 기존 패턴 유지 (순차 `for...of await`). 각 재귀 호출도 배치를 부모로 전파하기 위해 `options` 그대로 넘김
- [ ] 재귀 반환된 children은 기존 `children` 배열에 합치고, 하위에서 발생한 배치는 이미 onBatch로 부모에게 도달했으므로 **추가 호출하지 않음**

### 언어+버전 주의사항

- **Node 20 AbortController**: `AbortSignal` 전달만으로는 `fs.promises.readFile`이 자동 취소되지 않는다. `readFile(path, { signal })` 옵션 명시가 가능하지만 본 Phase에서는 배치 경계의 수동 체크로 충분. 파일 하나 읽는 동안의 지연은 수 밀리초 수준.
- **CJS async**: `link-parser.js`는 CJS. `async/await` 사용 가능. Top-level await는 불가.
- **`throw new Error('Aborted')` 명칭**: Web 표준과 비슷하게 이름을 `AbortError`로 맞추기 위해 `Object.assign(new Error('Aborted'), { name: 'AbortError' })` 로 던져 상위에서 `err.name === 'AbortError'` 분기 가능.

---

### LLM 코딩 주의사항

1. **step27 Phase 2 코드를 뒤엎지 말 것**: async 전환은 이미 완료 상태. 본 Phase는 **파라미터 확장만** 추가.
2. **Simplicity**: `onBatch`가 제공되지 않으면 기존 동작과 100% 동일해야 함. 옵션 기본값 `{}` 로 방어.
3. **Surgical**: `extractMarkdownLinks`, `markLinkedNodes`, `hasMdFiles`, `buildExternalNodes`, `collectLinkedPaths` 변경 금지.
4. **배치 중복 호출 방지**: 하위 디렉토리 재귀에서 이미 onBatch가 호출됨. 부모에서 다시 호출하면 같은 배치가 두 번 전달됨.
5. **AbortError 명칭 통일**: 모든 abort 경로에서 `err.name === 'AbortError'` 로 식별 가능하게.
6. **오류 격리**: onBatch 콜백 예외는 try-catch로 격리. 콜백 실패가 스캔 자체를 중단시키지 않도록.

### 테스트 시나리오

#### 정상 케이스
- **Given**: MD 파일 150개가 있는 폴더
  **When**: `buildDirectoryTree(root, 0, {count:0}, { onBatch: arr => chunks.push(arr) })`
  **Then**: `chunks.length === 3` (50+50+50), 각 배치는 최대 50개, 전체 children 수는 150

- **Given**: MD 파일 10개만 있는 작은 폴더
  **When**: 동일 호출
  **Then**: `chunks.length === 1`, 배치 내 노드 10개

#### 예외 케이스
- **Given**: 스캔 시작 후 100ms 시점 abort
  **When**: `controller.abort()` 호출
  **Then**: `buildDirectoryTree`가 `AbortError`로 reject, 이미 받은 batch는 유효

- **Given**: 읽기 권한 없는 파일 포함 폴더
  **When**: 스캔 실행
  **Then**: 해당 파일 `frontmatterName: null` + warn 로그, 나머지 정상

#### 경계값
- **Given**: `MAX_TREE_FILES` 상한에 근접한 폴더
  **When**: 스캔 실행
  **Then**: 상한 도달 시 즉시 루프 break, 이미 전달한 배치는 유효

- **Given**: `onBatch` 미지정
  **When**: 스캔 실행
  **Then**: 기존 동작과 동일 (회귀 없음)
