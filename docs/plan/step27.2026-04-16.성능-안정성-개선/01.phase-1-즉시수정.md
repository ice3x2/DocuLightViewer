## Phase 1: 즉시 수정 (독립, 1줄~수줄 변경) — 12건

### 목표

메인 프로세스 및 렌더러에서 독립적으로 수정 가능한 소규모 버그/성능 문제를 일괄 제거한다.
각 항목은 다른 항목과 의존성이 없으므로 병렬로 코딩 가능하며, 모두 완료 후 한 번에 검증한다.

### 코드 중복 주의

- `updateTrayMenu` 호출 지점은 `index.js` 내 여러 곳에 분산되어 있다. 함수 이름만 바꾸면 모든 호출자가 자동으로 디바운스 버전을 사용한다. 호출 지점을 직접 수정하지 말 것.
- `window-manager.js`의 `findWindowId()` 가 여러 메서드에서 호출된다. Map 역방향 조회로 교체 후 `findWindowId()` 함수 본체만 바꾸면 된다; 호출자는 그대로 둔다.
- `git-info.js` 캐시 키는 반드시 `path.normalize(projectPath)` 를 사용한다. 슬래시 정규화가 되지 않으면 동일 경로가 다른 키로 저장된다.

- [ ] Phase 1-5b: mcp-server.mjs의 ipcBuffer += chunk 패턴도 동일하게 Buffer[] 누적 방식으로 전환 (라인 48, 271) `IMPL-012`
- [ ] `socket.on('data', ...)` 핸들러 수정:
  - `buffer += chunk.toString('utf8');` → `chunks.push(chunk);`
  - 새 줄 탐색 전에 버퍼 변환: `let buffer = Buffer.concat(chunks).toString('utf8');`

- [ ] 구체적 패턴:
  ```javascript
  let chunks = [];
  socket.on('data', (chunk) => {
    chunks.push(chunk);
    let buffer = Buffer.concat(chunks).toString('utf8');
    chunks = [];
    let newlineIdx;
    while ((newlineIdx = buffer.indexOf('\n')) !== -1) {
      const line = buffer.slice(0, newlineIdx).trim();
      buffer = buffer.slice(newlineIdx + 1);
      if (line.length === 0) continue;
      // ... JSON.parse(line) ...
    }
    if (buffer.length > 0) {
      chunks = [Buffer.from(buffer, 'utf8')];
    }
  });
  ```
- [ ] 검증: ndjson 메시지 파싱 결과가 기존과 동일함

> **⚠️ mcp-server.mjs 주의 — `setEncoding('utf8')` 충돌 (리뷰 반영 2026-04-17)**:

> **mcp-server.mjs 전용 해결 방안** (택 1):

>     chunks.length = 0;

>   ```
> - **권장: (A) setEncoding 제거** — index.js와 패턴 통일, 유지보수 용이

### 언어+버전 주의사항

- **Node.js CJS**: `src/main/*.js` 파일은 모두 CommonJS이다. `require()` 패턴을 사용하며 top-level await 사용 불가.
- **ESM**: `src/main/*.mjs` 파일은 ESM이다. IMPL-012의 경우 `mcp-server.mjs`(ESM)도 수정 대상이다. `Buffer`는 Node.js 전역 객체이므로 ESM에서도 import 없이 사용 가능.
- **Electron 33.4.x**: `win.isAlwaysOnTop()` API는 Electron 1.x부터 존재한다. 버전 호환 문제 없음.
- **Buffer.concat()**: Node.js 내장 API. `Buffer[]` 배열을 받는다. 빈 배열 전달 시 빈 Buffer 반환 (안전).
- **`Date.now() + 30_000`**: 숫자 리터럴의 밑줄 구분자는 Node.js 12+ 에서 지원된다. Electron 33 은 Node.js 20.x를 포함하므로 문제 없음.
- **`TextEncoder`**: 브라우저 및 Node.js 11+ 에서 전역으로 사용 가능. renderer에서도 사용 가능.

### LLM 코딩 주의사항

1. **IMPL-006과 IMPL-034는 같은 파일**: `git-info.js` 를 단 한 번 열어 두 변경사항을 함께 적용한다. `Promise.all` → `Promise.allSettled` 전환과 캐시 추가를 동시에 처리한다.
2. **IMPL-007 findWindowId 교체 시**: 기존 `findWindowId` 함수가 어떻게 구현되어 있는지 먼저 확인한다. 선형 탐색(`for...of`, `Array.find` 등)으로 되어있을 것이다. 함수 본체만 교체하고 시그니처는 유지한다.
3. **IMPL-008 래퍼 패턴**: 기존 `updateTrayMenu` 함수를 `_doUpdateTrayMenu`로 이름 변경 후, 래퍼를 만든다. "기존 함수를 수정"하는 것이 아니라 "이름을 바꾸고 새 함수를 만드는" 패턴이다. 호출 지점은 수정하지 말 것.
4. **IMPL-012 Buffer 패턴**: 핵심은 "청크를 쌓고 → concat → 문자열 변환 → 처리 후 남은 부분 다시 청크로" 사이클이다. 루프 종료 후 남은 `buffer` 문자열을 반드시 다시 `chunks`에 저장해야 한다.
5. **IMPL-017 CSS 드래그**: `viewer.js` 에서 사이드바 드래그(리사이즈) 관련 mousedown 핸들러를 찾아 `document.body.classList.add('dragging')` 을 삽입하고, 해당 드래그의 종료 이벤트(mouseup on document)에 `remove('dragging')` 를 삽입한다. 기존 드래그 로직을 크게 변경하지 말 것.
7. **null 가드 항목들(IMPL-030, 031, 032)**: 기존 코드에서 해당 핸들러 위치를 정확히 찾은 후, 가드를 추가한다. 비즈니스 로직은 변경하지 않는다.
