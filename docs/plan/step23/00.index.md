# Step 23: Document Type System - Implementation Plan

## Overview

MCP `open_markdown` / `update_markdown` 호출 시 `docType` 파라미터를 지정하여 문서의 유형을 분류하는 기능. frontmatter에 자동 주입되며 뷰어 metabox에 아이콘+한국어 라벨로 표시된다.

## Document Types (10개)

| 값 | 한국어 | 아이콘 | 용도 |
|----|--------|--------|------|
| `note` | 노트 | 📝 | 일반 메모, 기본값 |
| `plan` | 계획 | 📋 | 구현/작업 계획 |
| `report` | 보고서 | 📊 | 분석/상태 보고서 |
| `completion` | 완료 보고서 | ✅ | 작업 완료 리포트 |
| `issue` | 이슈 | 🐛 | 버그/문제 보고 |
| `review` | 리뷰 | 🔍 | 코드/문서 리뷰 |
| `log` | 로그 | 📜 | 작업 로그, 변경이력 |
| `reference` | 참조 | 📖 | API 레퍼런스, 설정 가이드 |
| `guide` | 가이드 | 📘 | 튜토리얼, 사용법 |
| `spec` | 명세 | 📐 | SRS, SDS, 기술 명세 |
