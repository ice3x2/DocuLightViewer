# Phase 3: Viewer UI + i18n

## Objective

뷰어 metabox에서 docType을 아이콘+한국어 라벨로 표시하고, 4개 로케일 파일을 동기화한다.

## Prerequisites

- Phase 1 완료 (frontmatter에 docType 존재)

## Implementation Checklist

### 3.1 viewer.js — metabox에 docType 표시

**파일**: `src/renderer/viewer.js`

**DOC_TYPE_DISPLAY 인라인 매핑 추가**:
```javascript
const DOC_TYPE_DISPLAY = {
  note:       '📝',
  plan:       '📋',
  report:     '📊',
  completion: '✅',
  issue:      '🐛',
  review:     '🔍',
  log:        '📜',
  reference:  '📖',
  guide:      '📘',
  spec:       '📐',
};
```

**renderMetabox(meta) 수정**:
- `fieldLabels`에 `docType: t('viewer.metaDocType')` 추가
- docType 값 렌더링 시 아이콘 + 로케일 라벨 조합:
  ```javascript
  if (key === 'docType' && DOC_TYPE_DISPLAY[value]) {
    const icon = DOC_TYPE_DISPLAY[value];
    const label = t('docType.' + value) || value;
    valueCell.textContent = icon + ' ' + label;
  }
  ```
- docType 행을 metabox 테이블에서 **첫 번째** 또는 project 바로 다음에 배치 (시각적 우선순위)

**기존 패턴 재사용**: severity가 CSS 클래스명으로 인라인 매핑되는 것과 동일하게, docType도 아이콘 매핑을 인라인으로 처리.

### 3.2 viewer.css — docType 스타일 (선택적)

**파일**: `src/renderer/viewer.css`

- docType 행에 특별한 CSS는 불필요 (기존 metabox-table 스타일 재사용)
- 다만 아이콘이 있는 값 셀에 약간의 letter-spacing 추가 고려:
  ```css
  .metabox-value .doc-type-icon {
    margin-right: 4px;
  }
  ```
- **최소 변경 원칙**: 기존 스타일로 충분하면 CSS 추가하지 않음

### 3.4 설정 도움말 — {type} 토큰 설명

```
{type} - 문서 유형 (note, plan, report 등. 기본값: note)
```

## Test Scenarios

### 정상 케이스

**TC-3-01**: docType이 있는 문서 → metabox에 아이콘+라벨 표시
```
Given: frontmatter에 docType: plan
When: renderMetabox 호출
Then: metabox에 "📋 계획" (ko), "📋 Plan" (en) 표시
```

**TC-3-02**: 4개 로케일에서 모든 docType 라벨 표시
```
Given: 각 로케일로 전환
When: docType: review 문서 표시
Then: ko="🔍 리뷰", en="🔍 Review", ja="🔍 レビュー", es="🔍 Revisión"
```

### 예외 케이스

**TC-3-03**: frontmatter에 docType 필드 없음 (기존 문서) → docType 행 미표시
```
Given: frontmatter에 project, date만 있음
When: renderMetabox 호출
Then: docType 행 없음 (기존 동작 유지)
```

**TC-3-04**: 알 수 없는 docType 값 (이론적으로 불가하지만) → 값 그대로 표시
```
Given: frontmatter에 docType: unknown
When: renderMetabox 호출
Then: 아이콘 없이 "unknown" 텍스트만 표시
```

### 경계값

**TC-3-05**: docType 라벨이 긴 경우 (completion → "완료 보고서")
```
Given: docType: completion
When: metabox 렌더링
Then: "✅ 완료 보고서" — word-break 없이 한 줄 표시
```
