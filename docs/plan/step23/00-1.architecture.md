# Step 23: Document Type System - Architecture

## 1. System Context

MCP 클라이언트(Claude Desktop 등)가 `open_markdown` / `update_markdown` 호출 시 `docType` 파라미터를 전달하면, frontmatter에 자동 주입되고 뷰어 metabox에 아이콘+라벨로 표시된다. `{type}` 토큰은 저장 경로 서브디렉토리에서 사용 가능하다.

```
MCP Client ──▶ mcp-server.mjs / mcp-http.mjs
                      │ (docType param)
                      ▼
              frontmatter.js ── injectFrontmatter({ ..., docType })
                      │
                      ▼
              window-manager.js ── createWindow / updateWindow
                      │
                      ├──▶ viewer.js (renderMetabox → 아이콘+라벨)
                      ├──▶ mcp-save.js (resolveSubDir → {type} 토큰)
                      └──▶ search-engine.js (docType 필드 인덱싱/필터)
```

## 2. Data Flow

### 2.1 open_markdown 호출 시

```
1. MCP tool 수신: { content, docType?, project?, ... }
2. docType 미지정 → 기본값 "note" 주입
3. injectFrontmatter(content, { project, docName, description, docType })
4. IPC sendIpcRequest("open_markdown", { ..., docType })
5. index.js handleIpcMessage → windowManager.createWindow({ ..., docType })
6. saveMcpFile(store, { ..., docType }) → resolveSubDir에 {type} 토큰 전달
7. onWindowReady → renderer에 render-markdown IPC
8. viewer.js renderMetabox(meta) → docType 아이콘+라벨 표시
```

### 2.2 search_documents 호출 시

```
1. MCP tool 수신: { query, docType? }
2. searchEngine.search(query, { limit, project, docType })
3. BM25 filter: ov.docType === docType (ovFldNames에 docType 추가)
4. 결과에 docType 포함하여 반환
```

## 5. Key Design Decisions

### 5.1 docType 정의를 어디에 둘 것인가

**결정**: `frontmatter.js`에 `DOC_TYPES` 상수 정의, CJS export.
**근거**: frontmatter.js는 이미 MCP 서버들과 main process에서 공통 참조하는 유틸리티. 새 파일 생성 불필요.

### 5.2 기본값 처리 위치

**결정**: `injectFrontmatter()` 내부에서 docType 미지정 시 `'note'` 기본값 할당.
**근거**: 단일 지점에서 기본값 보장. MCP 서버 양쪽에서 중복 로직 방지.

### 5.3 뷰어에서 DOC_TYPES 참조 방법

**결정**: 뷰어(renderer)는 `DOC_TYPES`를 직접 import할 수 없으므로(sandbox), `viewer.js`에 동일 매핑을 인라인 정의.
**근거**: preload API로 전달하면 과도한 설계. 10개 타입은 정적이며 변경 빈도 극히 낮음.

### 5.4 {type} 토큰 기본값

**결정**: `resolveSubDir`에서 `{type}` 토큰은 `docType || 'note'`로 치환.
**근거**: `{severity}` 토큰이 `severity || 'general'`로 치환되는 기존 패턴과 동일.
