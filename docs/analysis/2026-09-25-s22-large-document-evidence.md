# S22 large-document indexing evidence

Issue [#45](https://github.com/ice3x2/DocuLightViewer/issues/45) uses `REL-DOC-007`, `IR-APP-013`, `FR-DOC-019`, and `IR-APP-010`. The isolated checkout began at `a5a615baeb20fba842f8d578c84900de2983b18f`. The tested source hash is `f7be1d510e9e697cf129a80b59f1f12d56bd73430468971d59c3219a2f9bd9c8`; the exact raw measurements are in [the bounded JSON artifact](./2026-09-25-s22-large-document-samples.json).

The real `publishSave`/indexed-origin path caps a document at 10 MiB. The deterministic fixture is 10,484,650 UTF-8 bytes, SHA-256 `98ef6b7bcb96965ba5a455d040b864dfc88a1c3b90e044e65c21043f3783d5b6`, leaving 1,110 bytes below that cap. It contains frontmatter, numbered headings and paragraphs, fenced JavaScript, Korean and English prose, and relative links. The separate legacy benchmark's sparse 160 MiB file tests bounded tokenizer behavior; it is outside the real save/read upper bound and is covered by the existing benchmark contract.

The S22 Electron case first commits a small warm-up document and confirms a keyword hit. A single owner worker then accepts the large document, reports active and chunk-progress markers, completes indexing, and returns a keyword hit for its unique marker. During that same active interval, the case collects 50 direct cached-owner-status, 25 direct BrowserWindow focus, and 25 direct BrowserWindow close samples, with each sample gated by worker progress. It records main heartbeat gaps from the active marker through the completion marker, including the final interval after the last timer tick. A second saved large-document revision is cancelled while active; the case confirms the cancelled terminal marker, the saved-file checksum, and the prior committed large-document keyword hit. Worker startup audit shows both SQLite connections opened on worker thread 1, with two opens total. This proves the isolated owner path. It does not measure product `index.js` status/cancel IPC or viewer close/focus request handlers; S20/S21 product-main cutover remains pending.
