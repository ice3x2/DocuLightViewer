## 1. Scope Overview

이 문서는 DocuLight 렌더러 UI와 마크다운 렌더링 파이프라인을 정의한다. marked 파싱부터 DOMPurify 정화, heading ID 생성, 이미지 resolve, Mermaid 렌더, highlight.js 적용, TOC 생성에 이르는 파이프라인과 테마, 설정 UI, 탭 멀티문서, 사이드바 파일 검색, PDF export, 이미지 경로 resolve를 포함한다.

## 2. Scope Boundaries

### In Scope

- 마크다운 렌더링 파이프라인 (marked → DOMPurify → heading IDs → images → mermaid → highlight → TOC)
- 라이트/다크 테마와 코드 테마 적용
- 설정 편집 UI (settings)
- 탭 기반 멀티문서 뷰 (tab-manager)
- 사이드바 파일 검색/필터 (sidebar-search)
- PDF export 모달 UI (pdf-export-ui)
- 상대 이미지 경로 resolve (image-resolver: file:// → data URI)
- 컨텍스트 메뉴, 찾기, 줌

### Out of Scope

- 메인 프로세스 IPC 핸들러 (APP)
- 사이드바 트리 빌드 알고리즘 (TREE)
- BrowserWindow 생명주기 (WIN)

## 3. Assumptions and Constraints

- marked v17은 heading ID를 생성하지 않으므로 렌더 후 slug 기반 ID를 부여한다 (CJK 지원).
- DOMPurify는 USE_PROFILES html 프로필 + details/summary 태그 허용으로 정화한다.
- 렌더러는 contextIsolation/sandbox 환경에서 contextBridge API만 사용한다.
- 탭 기능은 enableTabs 설정으로 제어한다.
